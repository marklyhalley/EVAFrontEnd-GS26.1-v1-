## Sobre o Projeto

O **E.V.A.** é um sistema biointeligente que une fungos micorrízicos, sensores IoT e inteligência artificial para:
- Regenerar solos degradados na Terra
- Viabilizar a colonização sustentável de Marte

## Estrutura de Pastas

```
eva-site/
├── index.html              ← Página 1: Problema
├── pages/
│   ├── tecnologia.html     ← Página 2: Tecnologia
│   ├── objetivos.html      ← Página 3: Objetivos / Fases
│   ├── beneficios.html     ← Página 4: Benefícios
│   └── aplicacao.html      ← Página 5: Aplicação no Dia a Dia
```

## Tecnologias Utilizadas

- **HTML5** semântico
- **CSS3** com variáveis CSS (`--var`), Flexbox e responsividade completa
- **Bootstrap 5.3** para grid e componentes
- **Google Fonts**: Exo 2, DM Sans, JetBrains Mono
- **Chart.js** (dashboard de métricas)
- **JavaScript** vanilla (ES6+)
